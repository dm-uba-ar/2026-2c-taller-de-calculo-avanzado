## **Recursos para escribir en LaTeX**

- [Overleaf](https://overleaf.com/) es un editor de LaTeX en línea. Cuenta con una [documentación para aprender LaTex](https://www.overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes).
- [Quiver](https://q.uiver.app/) es una herramienta en linea para hacer diagramas (salva vidas).
- [Detexify](https://detexify.kirelabs.org/classify.html) es una herramienta en línea que permite encontrar el código de LaTeX de muchos símbolos dibujandolos.
- [TexStudio](https://www.texstudio.org/) es un editor de texto de código abierto. Solo es una (muy útil) interfaz de edición, para que funcione hay tener previamente instalada una distribución de TeX en la computadora.
